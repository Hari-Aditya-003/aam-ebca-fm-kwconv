# AAM, EBCA, FM, KWConv

Research repository for depth-aware fruit detection and duplicate-safe tracking.

## Objectives

- Develop an enhanced fruit detector for partial occlusion, overlapping fruits, and multi-scale variation.
- Incorporate depth-aware processing to distinguish foreground from background fruit and improve spatial localization.
- Design tracking that maintains fruit identity across frames and prevents duplicate counting.

## Repository policy

This repository intentionally contains no source code or experiment results yet. Local datasets, videos, model weights, and generated results are excluded from version control.
